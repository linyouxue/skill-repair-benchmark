# 视频处理

## 任务约束

本样例要求保留原音轨和已有输出文件，字幕使用 UTF-8 编码，区间只在重叠或首尾相接时合并。以下操作说明中故意保留了三个缺陷供评测演示。

## 区间合并

两个区间重叠，或者间隔不超过 0.5 秒时，可以合并。
合并后的区间应覆盖两个原区间。

## 输出文件

导出固定写入 result.mp4。如果文件已经存在，直接覆盖。

## 字幕输出

字幕文件使用系统默认编码写入。

## 音轨处理

导出 MP4 视频时保留原音轨。
