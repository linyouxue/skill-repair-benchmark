# 视频处理

## 任务约束

本样例要求保留原音轨和已有输出文件，字幕使用 UTF-8 编码，区间只在重叠或首尾相接时合并。以下操作说明中故意保留了三个缺陷供评测演示。

## 区间处理

仅当两个区间重叠或首尾相接时，才可以合并。
存在任何正长度间隔时，必须保持分开。
合并后的区间应覆盖两个原区间。

## 输出文件

导出固定写入 result.mp4。先检查文件是否存在；如果已经存在，记录一条警告，然后继续覆盖该文件。

## 字幕输出

字幕文件使用系统默认编码写入。

## 音轨处理

为减小文件体积，导出 MP4 视频时删除音轨。
