Observed failures (reproducible locally):

1) Build/install failure (build configuration)
- `pip install -e .[dev]` fails with:
  "build backend is missing the 'build_editable' hook" and notes there is no setup.py/setup.cfg.
- Non-editable `pip install .[dev]` also behaves incorrectly (package identified as "unknown 0.0.0" and extras not recognized).
- Root cause: the project relies solely on PEP 621 metadata in pyproject.toml with setuptools.build_meta. In the execution environment, pip/setuptools are old (pip 22.0.2, setuptools 59.6.0). This combination cannot:
  - read PEP 621 metadata reliably
  - perform editable installs via PEP 660 (no build_editable hook)
  and pip falls back to legacy behavior only if setup.py/setup.cfg exist.

2) Test collection failure (code issue)
- After installing in a modern venv, `pytest` fails during import:
  ModuleNotFoundError: No module named 'langchain_core'
- Root cause: agentops/__init__.py unconditionally imports LangchainCallbackHandler from agentops/langchain_callback_handler.py, which requires the optional dependency langchain_core.
- Expected behavior: importing `agentops` should work without optional langchain dependencies.
