Important functions / fuzz targets (ujson)

High-value entry points
- ujson.loads(s: str|bytes|bytearray) -> Any
- ujson.dumps(obj, ...) -> str

Why these targets
- ujson is a native extension: fuzzing can catch memory safety issues (crashes) in C.
- loads() in particular is a classic parser boundary with complex control flow.

Existing tests / oracles (from /tests/test_ujson.py)
- Extensive coverage of loads/dumps round-trips, unicode edge cases, deep nesting, digit limits.
- Expected failures are typically ValueError / ujson.JSONDecodeError for invalid JSON.

Fuzzing oracle ideas
- Crash-only for native bugs (segfault, abort, ASan findings if enabled).
- For malformed JSON, ValueError/JSONDecodeError are acceptable.

Seed ideas
- "{}", "[]", "null", "true", "false", "\"text\"", "123", "-0.0", "NaN", "Infinity"
- Deep nesting and long numbers (bounded for time).
