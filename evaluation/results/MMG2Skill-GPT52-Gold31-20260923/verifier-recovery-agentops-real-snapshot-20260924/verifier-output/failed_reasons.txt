- `pytest` fails during test collection with:
  - `ModuleNotFoundError: No module named 'langchain_core'`

    `LangchainCallbackHandler` from `agentops/langchain_callback_handler.py`, which requires
    `langchain_core` and `langchain`.

Why this breaks the build:
- LangChain support is declared as an optional dependency (`[project.optional-dependencies].langchain`),
  but importing the base `agentops` package currently *requires* langchain packages.
- The test suite imports `agentops` without installing the optional extras, so tests fail at import time.

Root cause classification:
- Code issue (import-time optional dependency). Not a build configuration issue.

   - Wrap the `langchain_callback_handler` import in `try/except ImportError`.
   - Provide stub `LangchainCallbackHandler` / `AsyncLangchainCallbackHandler` that raise a clear
     error on instantiation, telling users to install `agentops[langchain]`.
2) Remove circular/self-imports inside `agentops/langchain_callback_handler.py`:
   - Replace `from agentops import ...` with relative imports (`from .client import Client`,
     `from .event import ...`, `from .helpers import get_ISO_time`).
