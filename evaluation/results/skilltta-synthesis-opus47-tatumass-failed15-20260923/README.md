# SkillTTA Opus 4.7 / Tatumass — 15-task submission

This directory is one self-contained evaluation method submission.

- `submission.json`: evaluation submission metadata.
- `tasks/<task>/repaired_skill/`: complete temporary SkillTTA bundle used by the method-skill rollout.
- `tasks/<task>/original_run/`: selected Claude Opus 4.7 original-skill run from the published source branch.
- `tasks/<task>/repaired_run/`: final valid SkillTTA method-skill rollout.
- `tasks/<task>/synthesis_provenance.json`: retrieval and synthesis provenance.
- `tasks/<task>/diagnosis/`: public request configuration and raw structured diagnosis response.
- `trajectory_timelines/`: deterministic Markdown exports generated by the official export script.

The original SkillTTA synthesis stage did not emit diagnoses. A supplemental evidence-grounded diagnosis stage was therefore run with the same Tatumass Claude Opus 4.7 configuration. It read only each original failed run and original Skill package; it did not read Gold, reference repairs, or the repaired run. `submission.json` contains all resulting structured diagnoses. No infrastructure-invalid retry is selected as a final run.
