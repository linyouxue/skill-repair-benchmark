ujson (UltraJSON) – notes for fuzzing / robustness testing

High-value APIs
- ujson.loads(s)
  - Native JSON parser; must not crash on arbitrary input.
- ujson.dumps(obj, **options)
  - Native serializer; historically sensitive to edge cases (refcounts, NaN/Inf, unicode, deep nesting).

Functions / behaviors to target
- loads() with:
  - arbitrary bytes decoded to str (with replacement)
  - arbitrary short/medium-length unicode strings
- dumps() with randomly generated JSON-serialisable objects:
  - nested lists/dicts with bounded depth
  - strings with '\x00', tabs, angle brackets, unicode astral symbols
  - floats, including extreme magnitudes
- Round-trip oracle when possible:
  - obj -> dumps -> loads should not crash

Expected/acceptable exceptions
- ValueError (invalid JSON)
- TypeError / OverflowError (non-serialisable or too-large numbers)
- Unicode-related errors (depending on input coercion)

Seed ideas
- Minimal JSON: 'null', 'true', '[]', '{}', '""', '0'
- Known tricky patterns: deeply nested arrays/objects, repeated backslashes/quotes
