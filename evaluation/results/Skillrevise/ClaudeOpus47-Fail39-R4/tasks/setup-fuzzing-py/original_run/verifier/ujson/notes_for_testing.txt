Fuzzing notes (ujson)

High-value inputs / boundaries
- Native extension JSON codec:
  - ujson.loads(str|bytes)
  - ujson.dumps(obj, ensure_ascii=..., escape_forward_slashes=..., encode_html_chars=...)

Suggested functions-under-test (FUTs)
1) ujson.loads(random_unicode)
   - Unicode handling, escapes, number parsing, nesting, invalid sequences.

2) ujson.dumps(obj) for small structured objects derived from the fuzzer input
   - Exercises encoder paths; historically sensitive for refcount / memory issues.

Oracles
- Crash-only: no segfaults / aborts.
- If loads succeeds: dumps(result) then loads(dumps(result)) should not crash.

Acceptable exceptions (treat as non-findings)
- ValueError / TypeError for invalid JSON
- OverflowError (extreme numeric conversions)

Suspicious exceptions
- MemoryError (potential DoS), AssertionError, SystemError
- Any native crash

Performance / DoS notes
- Cap nesting depth / output size when building objects.
- Cap input text length.
