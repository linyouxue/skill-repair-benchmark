Important functions / APIs to test (IPython)

High-value fuzz targets (input boundaries)

1) IPython.core.inputtransformer2.TransformerManager.transform_cell(cell: str) -> str
   - Why: transforms user code cells (magics, escapes, prompts). Complex parsing and state.
   - Inputs to vary:
     - Unicode cell strings with prompts, magics (%timeit, !shell), multiline blocks.
     - Partial/incomplete statements.
   - Expected failures: SyntaxError, IndentationError, tokenize.TokenError, ValueError.

2) IPython.core.inputtransformer2.TransformerManager.check_complete(cell: str)
   - Why: used for determining whether a block is complete; edge-cases in tokenization.

3) IPython.core.splitinput.split_user_input(line: str)
   - Why: parses "magic" and shell-escape syntax; should be robust to arbitrary text.

Existing tests
- IPython has extensive tests; fuzzing should focus on malformed/incomplete/mixed-encoding inputs and odd combinations of magics/escapes.

Fuzz harness note
- Avoid starting a full InteractiveShell; prefer pure helpers (TransformerManager, split_user_input).
- Enforce small input sizes (<= 4k) to avoid pathological tokenization behavior.
