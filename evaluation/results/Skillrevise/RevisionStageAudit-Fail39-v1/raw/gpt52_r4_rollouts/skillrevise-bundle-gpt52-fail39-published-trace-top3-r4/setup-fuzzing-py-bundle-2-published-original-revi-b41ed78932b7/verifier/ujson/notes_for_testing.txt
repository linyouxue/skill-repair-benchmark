Important functions / APIs to test (ujson)

High-value fuzz targets (native boundary)

1) ujson.loads(s: str|bytes)
   - Why: C extension JSON parser; high risk boundary.
   - Inputs to vary:
     - Arbitrary bytes (invalid utf-8), truncated JSON, deeply nested arrays/objects.
     - Numbers with huge exponents, lots of leading zeros, NaN/Inf spellings.
   - Expected failures: ValueError, OverflowError, UnicodeDecodeError/TypeError.

2) ujson.dumps(obj)
   - Why: C extension serializer; exercise type handling.
   - Inputs to vary:
     - Construct Python objects from fuzz bytes (dict/list with nested scalars), include bytes/unicode edge cases.
   - Expected failures: TypeError, OverflowError, ValueError.

Existing tests
- tests/ likely cover standard JSON compliance and special options.

Fuzz harness note
- For loads: feed bytes directly (and also decoded strings).
- For dumps: build a bounded nested structure from the input, then call dumps.
