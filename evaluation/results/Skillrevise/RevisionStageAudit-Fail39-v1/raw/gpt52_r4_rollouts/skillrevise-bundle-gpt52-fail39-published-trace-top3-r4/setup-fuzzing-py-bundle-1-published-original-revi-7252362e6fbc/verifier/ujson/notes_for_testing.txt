Notes for testing / fuzzing: ujson

High-value modules / boundaries
- ujson.loads(): JSON parsing boundary (C extension)
- ujson.dumps(): JSON serialization boundary (C extension)

Suggested functions-under-test (FUTs)
1) ujson.loads(json_text: str|bytes)
2) ujson.dumps(obj, **options)

Input ideas
- Arbitrary bytes decoded to unicode with replacement
- JSON edge cases: deep nesting, large numbers, exponents, unicode escapes, invalid surrogate pairs

Inferred oracles / properties
- No crash / no hang (especially important for native extension)
- If loads succeeds: dumps(obj) should succeed for JSON-serializable outputs
- Round-trip smoke: obj2 = loads(dumps(obj)) should not raise

Expected/acceptable exceptions
- ValueError (parse errors)
- TypeError (invalid object types)
- OverflowError
- UnicodeDecodeError (if we choose strict decoding)

Seed corpus ideas
- "null", "true", "false", "0", "[]", "{}"
- "{\"a\":1,\"b\":[2,3]}"
- "[\"\\u1234\", \"\\ud83d\\ude80\"]"
