Library: ujson (fast JSON encoder/decoder, C extension)
=======================================================

Important files:
- src/ultrajson.h, src/ultrajsonenc.c, src/ultrajsondec.c - C decoder/encoder
- python/JSONtoObj.c, python/objToJSON.c                  - Python bindings
- src/ujson module exposes: dumps, loads, encode, decode

Fuzz-worthy function under test:
- ujson.loads(bytes_or_str) - parses JSON input through hand-written C decoder.
  Classic parser boundary / native code - very fuzz-worthy for memory issues.
- ujson.dumps(obj) is also interesting but requires structured Python input.

Oracles:
- Must not crash the process.
- Library-expected exceptions: ValueError, TypeError, UnicodeDecodeError,
  OverflowError, RecursionError, MemoryError.
  (ujson raises ValueError on malformed JSON.)
- Round-trip (dumps(loads(x)) parses back) is a bonus oracle but not needed
  for the quick smoke run.

Harness plan:
- Consume raw bytes from FuzzedDataProvider.
- Call ujson.loads(data). Catch expected exceptions.
