Library: ipython (IPython interactive shell toolkit)
====================================================

Important files:
- IPython/core/inputtransformer2.py - TransformerManager.transform_cell:
    converts raw user cell source (incl. magics, %, !, ?) to pure Python.
    Regex-heavy, line-based parser.
- IPython/lib/pretty.py             - pretty(obj) repr formatter
- IPython/utils/text.py             - string utilities
- IPython/core/completer.py

Fuzz-worthy function under test:
- IPython.core.inputtransformer2.TransformerManager().transform_cell(str) -> str
  Pure-Python, no heavy deps (does not need tokenize of invalid python at top
  level - returns strings). Great parser-boundary target.

Oracles:
- Must not crash on arbitrary str input.
- Library-expected exceptions: SyntaxError, IndentationError, ValueError,
  TypeError, UnicodeError, tokenize.TokenizeError.

Harness plan:
- Instantiate TransformerManager once (module-level).
- For each fuzz input, decode as unicode and call tm.transform_cell(s).
- Catch expected exceptions.
