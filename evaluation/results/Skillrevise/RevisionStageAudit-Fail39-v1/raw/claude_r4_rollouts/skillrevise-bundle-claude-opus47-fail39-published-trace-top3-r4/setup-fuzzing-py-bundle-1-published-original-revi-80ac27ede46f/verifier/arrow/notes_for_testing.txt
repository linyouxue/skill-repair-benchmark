Library: arrow (datetime library)
================================

Important files:
- arrow/parser.py        - DateTimeParser, regex-heavy ISO 8601 and arbitrary format parsing
- arrow/factory.py       - ArrowFactory.get(): dispatches to parser based on input type
- arrow/api.py           - public module-level `arrow.get(...)` entry point
- arrow/util.py          - normalize_timestamp, is_timestamp
- arrow/formatter.py     - DateTimeFormatter

Fuzz-worthy function under test:
- arrow.get(str) - the top-level public entry point which internally runs
  arrow.parser.DateTimeParser.parse_iso() over arbitrary unicode strings.
  This is a classic parser/regex boundary -> excellent for fuzzing.

Oracles:
- Must not crash on any str.
- Expected exceptions (library-defined): ParserError (subclass of ValueError),
  ValueError, TypeError, OverflowError.
- Any other uncaught exception is suspicious.

Harness plan:
- Build str from FuzzedDataProvider.ConsumeUnicodeNoSurrogates.
- Call arrow.get(s). Catch expected exceptions.
