Library: arrow (https://github.com/arrow-py/arrow)
Purpose: Better dates & times for Python.

Selected FUT: arrow.api.get(*args, **kwargs)
File: /app/arrow/arrow/api.py (dispatches to arrow.factory.ArrowFactory.get)
Underlying parser: arrow.parser.DateTimeParser.parse_iso / .parse

Why this target:
- Input surface: user-controlled date/time strings and optional format strings.
- Boundary: ISO-8601 parsing with many branches (dates, times, offsets, fractions, week dates).
- Complexity: regex-driven parser with locale-aware tokens -- high branch count.
- Test gaps: tests exercise known-good strings; fuzzing explores malformed/edge Unicode and format strings.

Callable contract:
- `arrow.get(str)` or `arrow.get(str, fmt)` returns an Arrow instance.
- Expected failure modes raise `arrow.parser.ParserError`, `arrow.parser.ParserMatchError`,
  `ValueError`, `TypeError`, `OverflowError`.

Input model: bytes decoded to a str via FuzzedDataProvider; optionally second arg = format string.

Oracles (crash-only): any exception outside the allow-list is suspicious.

Dependencies: python-dateutil, tzdata.
