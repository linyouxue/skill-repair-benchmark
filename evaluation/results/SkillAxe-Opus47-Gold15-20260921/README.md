# SkillAxe / Claude Opus 4.7 / Gold 15

Archive of the completed 2026-09-21 SkillAxe batch: 15 original-failure tasks selected from the 31-task v25 Gold set. Diagnosis/repair and fresh task execution use `openrouter/anthropic/claude-opus-4.7`; the content judge uses GPT-5.5 medium.

## Contents

- `submission.json`: original diagnoses, portable repaired-bundle paths and recorded executor run IDs.
- `tasks/<task_id>/repaired_skill/`: complete method-produced bundle, verified against the exact `repaired_run/inputs/skills/` snapshot.
- `tasks/<task_id>/original_run/` and `repaired_run/`: all available run metadata, ACP/LLM trajectories, input snapshots, artifacts, trainer records and verifier outputs.
- `tasks/<task_id>/repair_inputs/` and `repair_generation/`: diagnosis/repair request, responses and generated changes.
- `trajectory_timelines/before/`, `after/` and `trajectory_timeline_index.json`: generated by the repository's `export_trajectory.py`. Original metadata is retained; `PACKAGING.json` explicitly pairs the baseline and repaired runs by task.
- `gold-evaluation/`: original content-judge results. `outcome-adjusted/`: separately labelled offline alternative statistics and their existing calculation scripts; these do not replace the original Gold judgments.
- `manifest.json`, `protocol.json`, `batch_state.json` and `EXPERIMENT.md`: source selection, configuration and recorded batch state.

## Recorded execution outcomes

6 PASS, 7 FAIL and 2 INFRA_ERROR. `jpg-ocr-stat` and `shock-analysis-supply` ended with recorded ACP conversation errors; their partial trajectories and null outcomes are retained. They have no verifier reward file and are not counted as valid FAIL. All 15 tasks have a submitted repaired bundle and original Gold evaluation.

The denominator is the 15 selected historical failures, not all 31 or 87 tasks. Original trajectories were reused: six baseline tasks used a 128,000-token output limit and the JPG baseline used 65 iterations; fresh runs used 32,768 tokens / 60 iterations. See `EXPERIMENT.md` for the recorded protocol.

Actual skill-tool invocation counts and prompt-exposure evidence remain in the run records; they are distinct measurements. The existing complete report records one skill-tool invocation across the 13 valid executions, with full-SKILL.md exposure evidence for all 13.
