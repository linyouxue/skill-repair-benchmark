# SkillGrad partial results archive

This directory is an incremental partial archive of formally completed `skillgrad-formal` tasks for benchmark version `manual-gold-defects-20260917-v25`. It is not the final 31-task submission.

The current archive contains four completed tasks. Raw ACP trajectories are the source of truth; `trajectory_timelines/` is generated by the repository's official `evaluation/results/export_trajectory.py` script.
