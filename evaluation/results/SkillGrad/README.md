# SkillGrad partial results archive

This directory is an incremental partial archive of formally completed `skillgrad-formal` tasks for benchmark version `manual-gold-defects-20260917-v25`. It is a **partial intermediate archive**, not the final 31-task submission.

The archive contains 11 tasks completed as of `2026-09-22T03:01:13.027079+00:00`. The canonical formal experiment was still running at that snapshot; tasks completed later are intentionally excluded from this increment.

Raw `trajectory/acp_trajectory.jsonl` files are the source of truth. `trajectory_timelines/` is generated by the repository's official `evaluation/results/export_trajectory.py` script. Infrastructure-invalid attempts remain in the canonical experiment and are not included under this method root.
