## Pattern addressed: `sandbox-path-access`
**Evidence:** Iteration failed before any domain work because evidence files were referenced via absolute host paths (blocked as “path escapes the allowed project root”), then via a non-existent relative filename—preventing trace/verifier/skill inspection and therefore preventing grounded edits.

**Patch:** Added a new L2 workflow section near the top of each `SKILL.md`:

- Locate the sandbox root via directory listing; operate only within that tree.
- Prefer harness-provided relative paths.
- If a path “escapes the allowed project root”, don’t try other absolute paths; instead copy/move artifacts under the sandbox root and read them there.
- Stop-condition: if evidence cannot be accessed, do not attempt domain changes until access is fixed.
