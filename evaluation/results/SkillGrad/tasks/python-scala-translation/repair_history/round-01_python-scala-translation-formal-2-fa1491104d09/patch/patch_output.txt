Applied the iteration-0 pattern **artifact-materialization-before-termination** by adding a hard workflow gate to the skill so runs cannot end without producing the required Scala deliverable(s).

### What changed
- **Edited**: `evolved_skills/python-scala-syntax-mapping/SKILL.md`
  - Added a new section: **“Workflow: Materialize required artifacts before ending”**
  - The section enforces:
    1. Identify required output paths (inventory).
    2. Write the Scala source to the exact required paths.
    3. Re-read the written files to confirm non-empty / intended content.
    4. Attempt Scala compilation when available and iterate on errors instead of terminating.

### Why this addresses the failure
The batch failure was not about translation correctness; it was a workflow termination bug where the run ended with an empty output inventory (missing `/root/Tokenizer.scala`). This patch adds a general, reusable “must materialize outputs” rule to prevent that class of failure.
