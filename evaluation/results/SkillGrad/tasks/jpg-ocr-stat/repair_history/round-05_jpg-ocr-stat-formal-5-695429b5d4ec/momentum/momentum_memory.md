### output-contract-excel-deliverable | workflow | ensure required output artifact is written to exact path with required schema and validated before termination
- anchor: deliverable-contract-save-validate-before-ending
- appeared_in: iter_0, iter_1, iter_2, iter_3, iter_4
- description: The executor may complete intermediate reasoning (e.g., OCR, parsing) but fail to create any output artifact, or create one at the wrong location/schema. This presents as an empty output inventory and/or a run ending "stuck" without a final save step. For deliverables like an Excel workbook, the contract includes: exact file path, sheet name(s), required columns, ordering constraints, and absence of extras. In iter_1 (jpg-ocr-stat), the agent never invoked any skills and looped tool calls until `MaxIterationsReached`, resulting in no `/app/workspace/stat_ocr.xlsx` being written. In iter_2, the agent terminated (`end_turn`) without ever writing `/app/workspace/stat_ocr.xlsx`. In iter_3, the run ended after only 2 tool calls and no skill invocations, again producing no workbook at the required path. In iter_4, the workbook was written but to the wrong location (e.g., a relative `workspace/...` path), so the harness still considered the deliverable missing.
- latest_executor_action: Treat the deliverable spec as a hard output contract. Early in the run, restate the exact output path and schema (absolute path, not a "close" substitute). Then drive execution toward creating the artifact immediately (even with partial/best-effort data if upstream steps are blocked). Before ending the run: (1) write the artifact to the exact required path; (2) immediately re-open/inspect it to validate existence, sheet name/count, column headers and order, and any required row ordering/uniqueness; (3) if any check fails, fix and re-export (do not continue iterating on upstream steps while the output contract is unmet). Additionally, avoid premature termination: do not `end_turn` while the required artifact is missing OR when it exists only at a nearby path. Use `Path(required_path).resolve()` and `out_path.exists()` checks against the contract path, not the current working directory.
