# Controlled Skill Repair Experiments

This directory collects results from the controlled Skill repair experiments.
Each repair method and model configuration should use a separate subdirectory.

Recommended layout:

```text
controlled-skill-repair-experiments/
├── README.md
├── wml-claude4.7/
└── <method>-<configuration>/
```

The controlled dataset release is `skill-repair-controlled-datasets-20261020`.
