## 4. 单轮直接修复基线

**负责人为林元靖。** 使用 6.2 sol 或 Astra，直接修改一轮 Skill，再交给 GPT-5.2 执行任务。

| 流程 | 实验安排 |
| --- | --- |
| 修复模型 | 6.2 sol 或 Astra，记录最终使用的模型与配置。 |
| 输入 | 原题、原始 Skill，以及与所比较方法相同的可见失败材料。 |
| 修复方式 | 用通用修复提示直接编辑一次，输出完整修后 Skill 包。 |
| 执行模型 | 固定为 GPT-5.2，与原包及现有方法在同一任务集上比较。 |
| 保存结果 | 逐题通过情况、修后 Skill、执行轨迹、模型用量、费用和耗时。 |
| 要观察的问题 | 强模型单轮修复能达到什么效果，现有方法相对这条基线还有多少收益，修复模型能力对结果有多大影响。 |

沿用 GPT-5.2 的已有失败样本，便于固定执行模型比较修复收益。“强模型直接修复可能取得较高通过率”作为本轮待检验的预期。
