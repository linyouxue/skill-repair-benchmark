- The failing invoker project is value/src/it/functional (copied to value/target/it/functional).
- In that invoker project, maven-compiler-plugin:3.1:testCompile fails with:

     Root cause: dependency resolution selects com.google.guava:guava:17.0, which does not contain
     MoreObjects (added in later Guava versions). The invoker tests require a newer Guava.

1) Edit value/src/it/functional/pom.xml (NOT anything under target/**):
   - Define <project.build.sourceEncoding>UTF-8</project.build.sourceEncoding> (and optionally
     project.reporting.outputEncoding).
   - Configure maven-compiler-plugin to use <encoding>${project.build.sourceEncoding}</encoding>
     so compilation is independent of platform locale.
2) In the same POM, add an explicit test dependency on:
     com.google.guava:guava:18.0
   This ensures MoreObjects exists and matches the already-declared guava-testlib 18.0.
